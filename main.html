AI-Assisted Agentic Testing System

My graduation project, sponsored by Siemens. It’s a VS Code extension that generates, runs, and repairs UI tests. A LangGraph orchestrator routes each request to one of four specialized agents — requirements analysis, unit testing, integration testing, and TDD — which work on the codebase through Model Context Protocol tools and safe TypeScript AST edits. Every generated suite is validated in a sandboxed Playwright + Jest run, and DSPy handles prompt optimization.

request → orchestrator (LangGraph)
        → { requirements · unit · integration · tdd }
        → MCP tools → workspace edits (ts-morph)
        → sandbox: Playwright + Jest → coverage → self-heal ↺
